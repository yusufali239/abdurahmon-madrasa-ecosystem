# 🚀 Как запустить проект в интернете — пошагово

Всё, что можно автоматизировать, уже автоматизировано. Вы делаете только то, для чего нужны **ваши аккаунты и пароли**.

После запуска будет **один адрес** вида `https://madrasa-xxxx.onrender.com`:

| Что | Адрес |
|---|---|
| Mini App (для учеников и учителей) | `…/app` — открывается кнопкой «🕌 Madrasa» в боте |
| Админ-панель | `…/admin` — вход через команду `/admin` в боте |
| Проверка сервера | `…/api/health` |

Сервер делает сам:
- создаёт таблицы в базе;
- заполняет базу начальными данными (предметы, пример «Sardor domla»);
- ставит в боте кнопку «🕌 Madrasa» для Mini App;
- запускает вопрос учителям в 08:00 и напоминания.

---

## Шаг 1. Строка подключения к базе (Supabase) — ~3 минуты

1. Зайдите на **supabase.com** и откройте свой проект.
2. Нажмите кнопку **«Connect»** вверху страницы.
3. Выберите **«Session pooler»** (это важно: **не** «Direct connection» — тот работает только по IPv6 и с хостинга не подключится).
4. Скопируйте строку. Она выглядит так:
   `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres`
5. Замените `[YOUR-PASSWORD]` на **пароль базы**, вместе с квадратными скобками.
   - Если пароль забыт: **Project Settings → Database → Reset database password**.
   - Лучше придумать пароль только из латинских букв и цифр: символы `@ # / ?` ломают адрес.
6. Сохраните получившуюся строку в заметки — она понадобится в шаге 4.

## Шаг 2. Ваш Telegram ID — 1 минута

1. Напишите боту **@userinfobot** в Telegram.
2. Он ответит числом, например `123456789` — это ваш ID.
3. Если админов несколько, запишите их ID через запятую: `123456789,987654321`.

## Шаг 3. Слить изменения в основную ветку (GitHub) — 1 минута

1. Откройте Pull Request: https://github.com/yusufali239/abdurahmon-madrasa-ecosystem/pull/1
2. Внизу нажмите зелёную кнопку **«Merge pull request»**, затем **«Confirm merge»**.

## Шаг 4. Запуск на Render — ~10 минут

1. Зайдите на **render.com** и нажмите **«Get Started»**. Зарегистрируйтесь **через GitHub**.
2. Вверху нажмите **«New +» → «Blueprint»**.
3. Подключите GitHub, если Render попросит. Выберите репозиторий **abdurahmon-madrasa-ecosystem**, ветку **main**.
4. Render сам прочитает файл `render.yaml` и покажет два сервиса: **madrasa** и **madrasa-redis**.
5. Он попросит заполнить 4 поля:

   | Поле | Что вписать |
   |---|---|
   | `DATABASE_URL` | строку из шага 1 |
   | `BOT_TOKEN` | токен бота из @BotFather (вида `123456:AAH…`) |
   | `ADMIN_IDS` | ваш ID из шага 2 |
   | `HAYRIYA_MBANK_NUMBER` | номер MBank фонда «Hayriya» |

6. Нажмите **«Apply»**. Render попросит привязать карту.
   - Тариф **Starter — примерно $7 в месяц**.
   - Плюс диск 1 ГБ для чеков и материалов — примерно $0.25 в месяц.
   - Бесплатный тариф не подходит: на нём сервер «засыпает», и вопрос учителям в 08:00 не придёт.
7. Подождите 5–10 минут, пока статус станет **«Live»** (зелёный).

> **Хотите начать без демо-учеников и демо-учителей?** До нажатия «Apply» (или до первого запуска) поменяйте `SEED_DEMO` на `false` во вкладке **Environment**. Тогда в базе будут только предметы и админы.

## Шаг 5. Проверка — 5 минут

1. Откройте `https://<ваш-адрес>.onrender.com/api/health`. Ответ должен содержать `"ok":true` и `"bot":true`.
2. В Telegram откройте своего бота и нажмите **/start**. Вы админ, поэтому сразу появится главное меню.
3. Внизу слева от поля ввода появится кнопка **«🕌 Madrasa»** — она открывает Mini App.
4. Отправьте **/admin**. Бот пришлёт ссылку на админ-панель (действует 10 минут).
5. С другого Telegram-аккаунта (например, телефона родственника) пройдите регистрацию как ученик:
   - `/start`;
   - паспорт, например `ID1234567`;
   - «Поделиться номером»;
   - имя;
   - «Talaba».
6. Вам придёт заявка — нажмите **«✅ Tasdiqlash»**.

Готово! 🎉

## Что ещё может понадобиться позже

- **Настоящая проверка паспорта (Tunduk).** Сейчас работает тестовый режим: паспорт с `0000` отклоняется, остальные принимаются.
  - Когда получите доступ к API Tunduk, программисту нужно будет подстроить файл `backend/src/tunduk/tunduk.service.ts` под их формат.
  - Затем добавить `TUNDUK_API_URL` и `TUNDUK_API_KEY` в Render → Environment.
- **Изменить настройки.** Render → сервис **madrasa** → **Environment** → изменить → **Save** (сервер перезапустится сам).
- **Посмотреть ошибки.** Render → сервис **madrasa** → **Logs**.
- **Важно:** не запускайте этот же бот (тот же `BOT_TOKEN`) одновременно где-то ещё — Telegram отдаёт сообщения только одному серверу.

## Проверка настроек на своём компьютере (необязательно)

```bash
cp .env.example .env     # впишите свои значения
npm install
npm run check            # покажет, что настроено неправильно, простыми словами
```
